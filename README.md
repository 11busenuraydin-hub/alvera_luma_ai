# ALVÉRA Luma AI

ALVÉRA Luma AI, ALVÉRA cilt bakım markası için geliştirilen Flask tabanlı yapay zekâ destekli web uygulamasıdır.

## Özellikler

- Flask tabanlı backend
- Ana sayfa
- Dashboard
- AI servis katmanı
- Ortam değişkenleri ile güvenli yapılandırma
- Render deployment desteği
